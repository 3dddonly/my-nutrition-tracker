MY NUTRITION TRACKER — iPhone setup

1. Create a PUBLIC GitHub repository named: my-nutrition-tracker
2. Upload these files into the repository root:
   index.html
   manifest.webmanifest
   sw.js
   icon-192.png
   icon-512.png
3. Open repository Settings > Pages.
4. Under Build and deployment choose:
   Deploy from a branch
   Branch: main
   Folder: / (root)
   Save.
5. Wait for GitHub Pages to publish the site. Open the published https://...github.io/... address in Safari on your iPhone.
6. In Safari tap Share (square with arrow) > Add to Home Screen > Add.

DATA AND PRIVACY
- Meals, daily totals, calorie goal and weight entries are saved in local browser storage on that iPhone.
- Data does not automatically sync between devices.
- In the History tab use Export data regularly to download a JSON backup.
- Import backup restores a previously exported JSON file.
- The AI prompt button copies a prompt for ChatGPT. The app itself does not call an AI API or estimate macros automatically; paste the prompt into ChatGPT, then enter the estimated numbers in the app.

My Nutrition Tracker – automatski obračun

1. Raspakuj ZIP.
2. U GitHub repository uploaduj SADRŽAJ ovog foldera (ne ZIP fajl), preko Add file > Upload files.
3. Potvrdi zamenu postojećih fajlova i klikni Commit changes.
4. Sačekaj GitHub Pages deployment, pa otvori aplikaciju i uradi Ctrl+F5. Na iPhone-u zatvori PWA i ponovo je otvori.

Aplikacija lokalno računa kalorije, proteine, ugljene hidrate i masti na osnovu ugrađene baze prosečnih nutritivnih vrednosti. Nije potreban ChatGPT niti internet za sam obračun. Ako namirnica nije prepoznata, aplikacija je prijavljuje i ne čuva nepotpun obračun.
Dnevni cilj je 3.200 kcal. Postojeći cilj 2.700 kcal se automatski prebacuje na 3.200 kcal.
